A Lean 4 formalization of

> Ahmed Bou-Rabee, Tuan-Minh Nguyen, Yuval Peres and Arvind Singh,
> *Limit shapes for centrally excited walks*.

[LaTeX source](paper/oct13.tex) · [Bibliography](paper/oct13-references.bib)

The current source is pinned in [ledger/oct13.yaml](ledger/oct13.yaml). Its unchanged
statements retain the existing certified types; `lem:local` keeps only the local-time
approximation. Proposition 4.1 uses the exit-time proof, and Lemma 5.2 uses the
shifted-square energy proof. The outer-radius and fluctuation anchors use the
curvature, maximum-principle and global-profile arguments. Every introduction theorem
is restated in `CERW/MainTheorems.lean`.

The redefined event of Section 5.1 is stated literally in
[CERW/LimitShapes/Event.lean](CERW/LimitShapes/Event.lean), and its polynomial
exceptional probability is proved in `CommonEvent.lean`. Both the contact and
separated-bracket source theorems use these produced uniform constants, with
legality derived almost surely from the walk law. The common-event proof uses a
direct tail bound for the actual first-exit stopped quadratic martingale.

## Build

Install [elan](https://github.com/leanprover/elan), then run:

```bash
lake exe cache get
lake build
lake build CERWAudit
```

The Lean toolchain and dependencies are pinned in [lean-toolchain](lean-toolchain)
and [lake-manifest.json](lake-manifest.json). `import CERW` loads the development.

To run the verification tools with Python 3.10 or later:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install ./tools/leanform
python -m leanform_tools.verify .
python tools/verify_oct13.py
```

To build the current paper, run `latexmk -pdf oct13.tex` from `paper/`.

## Layout

- `CERW/LimitShapes/`: current statements, common-event probability and deterministic proofs.
- `CERW/MainTheorems.lean`: full introduction theorem restatements.
- `CERW/Frozen/`: preserved statements for the earlier source pin.
- `CERW/Model/`: the walk, its law, local times and ranges.
- `CERW/Support/`: proofs of the paper's results.
- `CERW/Generic/`: general mathematical results used in the proofs.
- `CERWAudit/`: the Mathlib-only statement comparison and its solution.
- `ledger/`: statement hashes, source locations and mathematical readings.
- `paper/`: the manuscript, bibliography and figures.
