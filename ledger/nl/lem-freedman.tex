\paragraph{Paper (verbatim).}
\begin{lemma}\label{lem:freedman}
Let $p>0$. There exists $C(p)<\infty$ such that the following holds for every integer~$n\geq2$ and every real martingale~$Z$ whose increments have absolute value at most~$1$: with probability at least $1-Cn^{-p}$,
\begin{equation}\label{eq:freedman}
|Z_n-Z_0|\leq C\bigl(\sqrt{\langle Z\rangle_n\log n}+\log n\bigr)\, .
\end{equation}
\end{lemma}
Definitions the statement relies on (verbatim):
\textit{notation for brackets (lines 296--296)}
\item The $\sigma$-field generated by $X_0,\ldots,X_j$ is~$\mathcal F_j$. For martingales $Z_1$ and~$Z_2$, the brackets $\langle Z_1\rangle_n$ and~$\langle Z_1,Z_2\rangle_n$ are the predictable quadratic variation and covariation through time~$n$.
\textit{notation $n\ge2$ (lines 299--299)}
\item All estimates concern integers~$n\geq2$, so that $\log n>0$. In a statement that holds with probability at least $1-Cn^{-p}$ for all sufficiently large~$n$, enlarging~$C$ makes it hold for every $n\geq2$.
\paragraph{Transcription.}
\emph{Object mapping.}
\begin{itemize}
\item ``A real martingale $Z$'' is \verb!Z : ℕ → Ω → ℝ! with \verb!Martingale Z ℱ μ! for a filtration \verb!ℱ : Filtration ℕ m0! on an arbitrary probability space \verb!(Ω, m0, μ)! (\verb![IsProbabilityMeasure μ]!). Mathlib's \verb!Martingale! is adaptedness plus $\mathbb E(Z_j\mid\mathcal F_i)=Z_i$ for $i\le j$; it implies integrability of every $Z_i$. The lemma does not fix the filtration: it holds for every filtration to which $Z$ is a martingale, and $\langle Z\rangle$ is taken with respect to that filtration.
\item ``Increments have absolute value at most $1$'' is \verb!∀ᵐ ω ∂μ, ∀ t, |Z (t + 1) ω - Z t ω| ≤ 1! (almost surely, for all times; martingales are defined up to null sets).
\item $\langle Z\rangle_n$ is \verb!CERW.predBracket μ ℱ Z Z n ω! $=\sum_{t<n}\mathbb E\bigl((Z_{t+1}-Z_t)^2\mid\mathcal F_t\bigr)(\omega)$, the predictable quadratic variation through time $n$ (line 296), so that $\langle Z\rangle_n\le n$ as used in the paper's proof. It is a conditional expectation, defined up to a null set; the event below is unaffected because it is measured by $\mu$.
\item $\log n$ is \verb!Real.log n! for \verb!2 ≤ n! (line 299).
\end{itemize}

\emph{Reading choices.}
\begin{enumerate}
\item \textbf{Quantifier order.} \verb!∀ p, 0 < p → ∃ C, 0 < C ∧ ∀ n, 2 ≤ n → ∀ (Ω μ ℱ Z), Martingale Z ℱ μ → (increments) → ..!: $C=C(p)$ depends on $p$ only, not on $n$, the space, the filtration or $Z$.
\item \textbf{Probability.} ``With probability at least $1-Cn^{-p}$'' is \verb!μ {ω | ¬ |Z n ω - Z 0 ω| ≤ C * (Real.sqrt (predBracket μ ℱ Z Z n ω * Real.log n) + Real.log n)} ≤ ENNReal.ofReal (C * n ^ (-p))!, the outer measure of the complement; one $C$ for the constant in the inequality and in the probability, as in the paper. $\langle Z\rangle_n\ge0$ almost surely, so \verb!Real.sqrt! is the true square root off a null set.
\item There is no dimension and no norm in this lemma, so no hypothesis \verb!2 ≤ d! appears.
\end{enumerate}
