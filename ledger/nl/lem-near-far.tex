\paragraph{Paper (verbatim).}
\begin{lemma}\label{lem:near-far}
There exists $C(d,\drift)<\infty$ with the following property. Let $1\leq w\leq b$ and $\lambda\geq1$. Let $D$ be a measurable subset of $\{v\in\R^d:b\leq|v|\leq b+w\}$ such that $|D\cap B((b+w)u,t)|\leq\lambda t^{d-1}$ for every unit vector~$u$ and every $t\geq w$, and $\int_D|v-y|^{2-d}\dd v\leq\lambda b$ for all $y\in\R^d$. Then every $y\in\R^d$ with $b\leq|y|\leq b+w$ satisfies
\begin{equation*}
U_D^+(y)\leq C\bigl(\lambda w^{d-1}\bigr)^{\nf1d}+C\lambda\, .
\end{equation*}
\end{lemma}
Definitions the statement relies on (verbatim):
\textit{$U_D^+$ (lines 1122--1125)}
For a bounded measurable set~$D\subset\R^d$ and $y\in\R^d$, the potential of~$D$ with its negative contributions discarded is
\begin{equation*}
U_D^+(y)\coloneqq\frac{2\drift}{\omega_d}\int_D\left[u_v\cdot\frac{v-y}{|v-y|^d}\right]_+\dd v\, .
\end{equation*}
\paragraph{Transcription.}
Standing assumptions: \verb!hd : 2 ≤ d!, \verb!0 < ε!, \verb!ε < 1 / d! ($\drift=\varepsilon$). $U_D^+$ (line 1124) is \verb!CERW.positivePotential d ε D y! $=\frac{2\varepsilon}{\omega_d}\int_D\max\{u_v\cdot(v-y)|v-y|^{-d},0\}\,dv$, with $u_v=\|v\|^{-1}v$ (\verb!CERW.unitDir!, $u_0=0$) and the integrand read as $0$ at $v=y$. All integrals in the statement are Bochner integrals of functions that are integrable for bounded measurable $D$ (here $D\subset\{b\le|v|\le b+w\}$), so no junk value $0$ arises.

\emph{Quantifiers.} $\forall\varepsilon\in(0,1/d)\ \exists C>0\ \forall w,b,\lambda\in\R$ with $1\le w\le b$ and $1\le\lambda$, $\forall D$ measurable with \verb!D ⊆ {v | b ≤ ‖v‖ ∧ ‖v‖ ≤ b + w}!, then the two hypotheses, then $\forall y$ with $b\le\|y\|\le b+w$. So $C=C(d,\varepsilon)$ precedes $w,b,\lambda,D$.

\emph{Hypotheses.} (1) for every $u$ with $\|u\|=1$ and every $t\ge w$: \verb!volume (D ∩ Metric.ball ((b + w) • u) t) ≤ ofReal (lam * t ^ (d - 1))!; the exponent $d-1$ is a natural-number power and $d\ge2$, so there is no truncated subtraction; balls are open. (2) for every $y\in\R^d$: \verb!∫ v in D, ‖v - y‖ ^ (2 - (d:ℝ)) ≤ lam * b! (real exponent $2-d\le0$; for $d=2$ the integrand is $1$).

\emph{Conclusion.} \verb!positivePotential d ε D y ≤ C * (lam * w ^ (d - 1)) ^ (1/(d:ℝ)) + C * lam!; the base $\lambda w^{d-1}\ge1$, so the real power is the true power.
