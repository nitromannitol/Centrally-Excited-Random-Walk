\paragraph{Paper excerpt.}
\begin{verbatim}
\item \underline{\emph{Radii in the plane}}: let $d=2$. For every $p>0$ there exists $c(\drift,p)>0$ such that, for all sufficiently large~$n$,
\begin{equation}\label{eq:planar-polynomial-lower}
\P\bigl(r_n-\Rin(n)\geq c\sqrt{r_n\log n}\bigr)\geq n^{-p}
\qquad\text{and}\qquad
\P\bigl(\Rout(n)-r_n\geq c\sqrt{r_n\log n}\bigr)\geq n^{-p}\, .
\end{equation}
\end{verbatim}
\paragraph{Lean statement.}
\begin{verbatim}
theorem CERW.Frozen.sharp_radii {d : ℕ} (hd : d = 2) :
    let ωd : ℝ := (volume (Metric.ball (0 : EuclideanSpace ℝ (Fin d)) 1)).toReal
    ∀ ε : ℝ, 0 < ε → ε < 1 / (d : ℝ) →
    let r : ℕ → ℝ := fun n => ((d + 1) * n / (2 * d * ε * ωd)) ^ ((1 : ℝ) / (d + 1))
    ∀ p : ℝ, 0 < p → ∃ c : ℝ, 0 < c ∧ ∃ n₀ : ℕ,
      ∀ {Ω : Type u} [MeasurableSpace Ω] (μ : Measure Ω) [IsProbabilityMeasure μ]
        (X : ℕ → Ω → Site d), CERW.IsCERW μ ε X → ∀ n : ℕ, n₀ ≤ n →
        let Ein : Set Ω :=
          {ω | c * Real.sqrt (r n * Real.log n) ≤ r n - CERW.innerRadius (X · ω) n}
        let Eout : Set Ω :=
          {ω | c * Real.sqrt (r n * Real.log n) ≤ CERW.maxRadius (X · ω) n - r n}
        MeasurableSet Ein ∧ ENNReal.ofReal ((n : ℝ) ^ (-p)) ≤ μ Ein ∧
          MeasurableSet Eout ∧ ENNReal.ofReal ((n : ℝ) ^ (-p)) ≤ μ Eout
--
\end{verbatim}
\paragraph{Transcription.}
$d=2$ is \texttt{hd : d = 2}; $\kappa\in(0,1/d)$ is \texttt{ε}; $r_n$, $\omega_d$ as in thm-shape. The order is $\forall p>0,\ \exists c>0,\ \exists n_0,\ \forall(\Omega,\mu,X)$ with \texttt{IsCERW}, $\forall n\ge n_0$, which reads ``for every $p$ there is $c(\kappa,p)>0$ such that for all sufficiently large $n$'': $c$ and $n_0$ are fixed before the probability space (they may be taken so, because the events depend only on the path and the law of the path is determined by \texttt{IsCERW}). $r_n-R_{\rm in}(n)\ge c\sqrt{r_n\log n}$ is \texttt{c * √(r n * log n) ≤ r n - innerRadius (X · ω) n}, and $R_{\rm out}(n)-r_n\ge\dots$ is the analogous set with \texttt{maxRadius}. A lower bound on a probability is written with \texttt{MeasurableSet E} and $\mathrm{ofReal}(n^{-p})\le\mu E$ (repository convention).
