Theorem (lines 130--152):
\begin{verbatim}
\begin{theorem}[Fluctuation bounds]\label{thm:fluctuations}
Let $d\geq2$ and $0<\drift<\nf{1}{d}$, and consider the centrally excited random walk. For every $p>0$ there exists $C(d,\drift,p)<\infty$ such that, for every integer~$n\geq2$, the following bounds hold simultaneously with probability at least $1-Cn^{-p}$.
\begin{enumerate}[label=\textup{(\roman*)}]
\item \underline{\emph{Radii}}:
\begin{equation*}
\begin{aligned}
|\Rin(n)-r_n|&\leq C\sqrt{r_n\log n}&&\text{and}\quad&\Rout(n)-r_n&\leq C\sqrt{r_n}(\log n)^{\nf52}&&\text{if } d=2\, ,\\
|\Rin(n)-r_n|&\leq C\log n&&\text{and}\quad&\Rout(n)-r_n&\leq C(\log n)^{d+1}&&\text{if } d\geq3\, .
\end{aligned}
\end{equation*}
\item \underline{\emph{Volume}}:
\begin{equation*}
\bigl|r_n^{-1}D_n\mathbin{\triangle}B(0,1)\bigr|
\leq C\begin{dcases}\sqrt{\frac{\log n}{r_n}},&d=2,\\\frac{\log n}{r_n},&d\geq3\end{dcases}\, .
\end{equation*}
\item \underline{\emph{Local times}}:
\begin{equation*}
\max_{x\in\Z^d}\bigl|\ell_n(x)-2d\drift(r_n-|x|)_+\bigr|
\leq C\begin{cases}\sqrt{r_n}(\log n)^{\nf32},&d=2,\\\sqrt{r_n\log n},&d\geq3\end{cases}\, .
\end{equation*}
\end{enumerate}
Moreover, almost surely these bounds hold for all sufficiently large~$n$.
\end{theorem}
\end{verbatim}
\paragraph{Transcription.} Parameters $d,\kappa,p$ precede the constant, which precedes the probability space: the
Lean order is \texttt{hd, ε, p, ∃ C > 0, ∀ Ω μ X}, matching $C(d,\kappa,p)$. \texttt{Good C Y n} is the conjunction of the
three parts (i)--(iii) for the path $Y$ at time $n$, with the $d=2$ / $d\ge3$ split written as \texttt{if d = 2 then … else …}
(so the \texttt{else} branch is $d\ge3$ under \texttt{hd}); \texttt{CERW.innerRadius} is $\inf_{y\notin D_n}|y|$,
\texttt{CERW.maxRadius} is $\max_{0\le j\le n}|X_j|$, \texttt{CERW.cellSet} is $D_n=\bigcup_{x\in A_n}C_x$, and the maximum over
$x\in\mathbb Z^d$ in (iii) is a universally quantified bound. The volume $|r_n^{-1}D_n\mathbin\triangle B(0,1)|$ is
\texttt{volume (((r n)⁻¹ • cellSet Y n) ∆ ball 0 1)}: the scaling applies to $D_n$ only (the audit found that the draft
omits the inner parentheses, and then Lean parses \texttt{•} below \texttt{∆}, scaling the symmetric difference). ``With probability at
least $1-Cn^{-p}$, for every integer $n\ge2$'' is $\mu\{\omega:\neg\,\mathrm{Good}\}\le\mathrm{ofReal}(Cn^{-p})$ for all realizations and
all $n\ge2$ (outer measure of the exceptional event). ``Moreover, almost surely these bounds hold for all sufficiently large $n$'' is
\texttt{∀ᵐ ω, ∀ᶠ n, Good C (X · ω) n} with the same $C$ as the probability bound for that $p$ (author ruling). The constant is
taken positive, which loses nothing since enlarging $C$ weakens both clauses.
