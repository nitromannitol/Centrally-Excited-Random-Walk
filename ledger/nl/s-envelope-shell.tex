% s-envelope-shell: eq:shellW from an envelope; the error scale of eq:global (backfilled twin).
\paragraph{Statement.} If $\ell_n\leq c_0(b-|\cdot|)_++A$ everywhere and $r\geq b+3$ then $M_{\rm sh}(r)\leq A$. If $0\leq M\leq C_0N$, $N,L\geq1$ then $\sqrt ML+L\leq(\sqrt{C_0}+1)\sqrt NL$ and $\sqrt{ML}+L\leq(\sqrt{C_0}+1)(\sqrt{NL}+L)$.
\paragraph{Proof.} Shell sites have $|y|\geq r-3\geq b$, so $(b-|y|)_+=0$. The second part is monotonicity of the square root.
