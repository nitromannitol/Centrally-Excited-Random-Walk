% s-sstar: eq:sstar-lower and eq:preconditions (deterministic form).
\paragraph{Statement.} For $C_d,C\geq0$ there are $c,C'>0$ such that for large $n$: if $M,s\geq0$, $n\leq Ms^d$ and $M\leq C_ds+CL^2$, then
$s\geq cN$, $M\leq C's$ and $\sqrt ML+L\leq C'\sqrt sL$.
\paragraph{Proof.} $n\leq(C_ds+CL^2)s^d$. By s-sstar-arith (with the constant $\max(C_d,C,1)$) this is impossible if $s<cN$. Then $L^2\leq s$ for large $n$,
since $L^2/N\to0$ (s-scale-limits); so $M\leq(C_d+C)s$. Also $s\geq1$, so $\sqrt ML+L\leq(\sqrt{C_d+C}+1)\sqrt sL$.
