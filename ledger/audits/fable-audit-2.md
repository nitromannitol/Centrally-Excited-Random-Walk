## 5. Independent re-derivation

**`prop:coarse` from `cerw-flat.tex:547-561` and the notation at 106-132, 315-339.** Fix an integer `d ≥ 2` and `ε ∈ (0, 1/d)`. Let `(X_j)` be the walk on `ℤ^d` started at 0 whose first departure from a site `x ≠ 0` (i.e. `X_j = x ∉ {X_0,…,X_{j−1}}`) has law `q_x(±e_i) = 1/(2d) ∓ (ε/2)x_i/|x|` and all other departures are SRW. With `A_n = {X_0,…,X_{n−1}}`, `R_n = |A_n|`, `ℓ_n(x) = #{j<n : X_j = x}`, `M_n = max_x ℓ_n(x)`, `H_n = max_{j ≤ n}|X_j|`, `N = n^{1/(d+1)}`: for every `p > 0` there exist `c, C > 0` depending only on `(d, ε, p)` such that for every integer `n ≥ 2`, `P(cN^d ≤ R_n ≤ CN^d ∧ cN ≤ M_n ≤ CN ∧ cN ≤ H_n ≤ CN) ≥ 1 − Cn^{−p}`.
Comparison with `Frozen/CoarseBounds.lean:39-50`: identical. `(d, ε, p)`-dependence is realized by `∀ε ∀p ∃c C` before `∀{Ω} μ X, IsCERW μ ε X →`; "probability ≥ 1−Cn^{-p}" is `μ{¬(…)} ≤ ofReal(C n^{-p})` (outer measure, at least as strong); `R_n = (departureRange (X·ω) n).card`, `M_n = maxLocalTime`, `H_n = maxRadius`, each checked against `Model/Occupation.lean:22-59` (`departureRange = (range n).image X`, `maxLocalTime = sup over A_n of ℓ_n`, `maxRadius = sup' over range (n+1) of euclidNorm ∘ X`). The law: `Model/Law.lean:27-37` (`X 0 = 0` a.s.; cylinder factorization through `stepProb`) and `Model/Kernel.lean:30-46` (`firstStep` gives `1/(2d) − (ε/2)x_i/|x|` at `+e_i`, `+` at `−e_i`; `stepProb` selects it iff `x n ≠ 0 ∧ x n ∉ image x (range n)`), matching `cerw-flat.tex:108-116`.

**`lem:local` from `cerw-flat.tex:380-414`.** Same walk. `L = log(n+2)`; `λ_n = L^2` (d=2), `L` (d≥3); `e_n(m) = √m·L + L` (d=2), `√(mL) + L` (d≥3); `ℓ_{s,t}(x) = #{s ≤ j < t : X_j = x}`, `M_{s,t} = max_x ℓ_{s,t}(x)`, `k_{s,t} = #{s ≤ j < t : X_j ∉ A_j}`; `ℓ̃_n = ℓ_n(x)` on the half-open cell `C_x = x + [−1/2,1/2)^d`; `D_n = ⋃_{x∈A_n} C_x`; `U_D(y) = (2ε/ω_d)∫_D u_v·(v−y)|v−y|^{−d}dv`. There is `C_d` (depending only on `d`) such that for every `p>0` there is `C = C(d,ε,p)` with: for every `n ≥ 2`, with probability `≥ 1 − Cn^{−p}`, simultaneously `M_n ≤ C_d ε R_n^{1/d} + Cλ_n`; `M_{s,t} ≤ C_d ε k_{s,t}^{1/d} + Cλ_n` for all `0 ≤ s < t ≤ n`; `|ℓ̃_n(y) − U_{D_n}(y)| ≤ C e_n(M_n)` for all `y ∈ ℝ^d`, `|y| ≤ 2n`.
Comparison with `Frozen/LocalTimePotential.lean:42-62`: identical, with `∃Cd, 0<Cd ∧ ∀ε … ∀p … ∃C` realizing "C_d depends only on d". `freshCount` (`Model/Occupation.lean:67`) counts `j ∈ Ico s t` with `X j ∉ departureRange X j`, i.e. `I_j = 1{X_j ∉ A_j}` including `j = 0` as in the paper (`cerw-flat.tex:335-336`). `potential` (`Model/Potential.lean:31-33`) is the Bochner integral of `inner (unitDir v) (v−y) / ‖v−y‖^d` over `D`, with `unitDir 0 = 0` per `cerw-flat.tex:334-335`; the value at `v = y` is 0 (null set). `cellLocalTime` (`Occupation.lean:108`) is `ℓ_n(cellCenter v)` with `cellCenter v = ⌊v_i + 1/2⌋`, which is the half-open cell convention.
