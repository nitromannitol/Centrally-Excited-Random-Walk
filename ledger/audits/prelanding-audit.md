## 4. Deep check A: `Limit/SiteFluctuations.lean` (Theorem 8.3, paper `:1462-1528`)

Structure of the Lean proof against the paper:

* Step 1 (bracket): `ae_abs_predBracket_sub_le` gives `|⟨M^f⟩_n - Σ_{x ∈ A_n} ℓ_n(x) Γ(f,f)(x)| ≤ K Σ_{x ∈ A_n} (1+|x|)^{2-2d}`, with `Γ` the file-local `gammaBr` (equal to `eq:site-gamma`: `(1/2d) Σ_e (Δ_e f)(Δ_e g) - Δf Δg`).
* Step 2 (`d ≥ 3`): `gamma_tsum_high` proves summability and `Σ_x Γ(f_s, f_s) = Σ_{ij} s_i s_j (2G(y_i - y_j) - 1_{y_i = y_j})` (summation by parts on boxes, with the flux bound `gamma_tsum_high_flux_bound`); `tendsto_bracket_high` gives `⟨M^f⟩_n / r_n → 2dε Σ Γ`. This matches the paper's Step 2.
* Step 3 (`d = 2`): `gamma_ball_sum_planar` proves `|Σ_{x ∈ B_r} (r - |x|) Γ(f,f)(x) - (4/π)(Σ s_i)² r log r| ≤ C r`; `tendsto_bracket_planar` then gives `⟨M^f⟩_n / (r_n log r_n) → 4ε (4/π)(Σ s_i)² = (16ε/π)(Σ s_i)²`, equal to `Σ_{ij} s_i s_j covN`. This matches the paper (`16ε/π`).
* CLT (`tendstoInDistribution_of_bracket`): applies `MartingaleCLT` to the Dynkin martingale `S = M^{f}` for `f = -Σ t_i g_{y_i}` with the deterministic normalization `s_n = max(σ_n, 1)` and `v = quadratic form`. The two hypotheses of the External are produced, not assumed: the conditional Lindeberg sum is a.e. zero for `n` with `δ s_n > K` (the increments are a.s. bounded by `K`, `condExp_congr_ae`), and the bracket convergence in measure comes from the a.s. convergence (`tendstoInMeasure_of_tendsto_ae`, with `predBracket n` a.e. strongly measurable). The External needs `v : ℝ≥0` including `0`, which occurs in the plane for `Σ t_i = 0`; Hall-Heyde Cor. 3.1 allows a zero limit (the paper says so in Step 4 of its proof, `:1491-1528`), and the statement quantifies `∀ v : ℝ≥0`. The nesting condition of Hall-Heyde is vacuous because the limit variance is constant and the σ-fields do not depend on `n`.
* LIL (`lil_of_bracket`): applies `StoutLIL` with the constant predictable bound `B = K`; the three side conditions are proved: `V_n → ∞` from `V_n / σ_n² → c > 0`, `B_n √(log log max(V_n, e^e)) / √V_n → 0` (`lil_of_bracket_sqrt_loglog_div`), and the comparison of `√(2 V_n log log V_n)` with `lil_n = √(2 σ_n² log log n)` through `log log V_n / log log σ_n² → 1` and `log log σ_n² / log log n → 1` (`lil_of_bracket_loglog_ratio`, `loglog_sigmaN`), then `lil_of_bracket_convert` turns the two-sided `(1 ± δ')` statement into the `(√v ± δ) lil_n` statement. Both signs are obtained from the martingales `±M^{y}` (`lil_site`, coefficient `-sg`).
* Step 5 (potential term): `ae_potential_term_le` combines the pointwise decomposition `|ℓ - U + M^y| ≤ C log(n+2)` (`exists_abs_localTime_sub_potential_add_dynkin_le`, a proved Support theorem), `hcenter` (Lemma 8.2), `hmom` (Theorem 8.1(ii), through `hmom hd hCLT hLIL ... .2.2` with the two Externals supplied from the theorem's own binders) and `ae_walk_le` (`|X_n| ≤ 2 r_n`, from `hfluct`), and `potential_term_bound` is the deterministic bookkeeping `|ℓ - P + M| ≤ a + b + (2ε/ω_d) s₁ r^{(3-d)/2} + 4/ω_d`. The error `errScale = (log(n+2))³ + r_n^{(3-d)/2} √(log log n + 1)` is `o(σ_n)` (`errScale_div_sigmaN`). This matches the paper's Step 5.
* Vectors (third conjunct): `tendstoInDistribution_vector` is Cramér-Wold with `multivariateGaussian 0 C`. Mathlib's `multivariateGaussian` equals `dirac` when `C` is not positive semidefinite (`multivariateGaussian_of_not_posSemidef`), so the covariance PSD claim is load-bearing and is proved, not assumed: `covN_posSemidef` follows from symmetry (`covN_comm`, `srwGreenInf_neg`) and `covN_quad_nonneg`. For `d = 2` the quadratic form is `(Σ s_i)² · 16ε/π ≥ 0`; for `d ≥ 3` it equals `2dε Σ'_x Γ(f_s, f_s)(x)` by `gamma_tsum_high`, and `Γ(f, f) ≥ 0` is `gammaBr_self_nonneg` (a conditional variance). `covN_self_pos` uses `G(0) ≥ 1` (`one_le_srwGreenInf_zero`) so the one-dimensional limit is a non-degenerate Gaussian. The matrix in the statement `Matrix.of fun i j => cov (y i) (y j)` is `covN` by `rfl` (the final `refine` is accepted).
* The one-dimensional parts are the case `k = 1` of the combination theorem (`clt_site` is `clt_combo` with `t = 1`).

The two Externals enter only through `hCLT`, `hLIL`, which are the binders of the Prop `site_fluctuations` itself (and are passed to `hmom`, whose Prop has the same binders). Independent plausibility of the two Externals as stated: `MartingaleCLT` is Hall-Heyde Cor. 3.1 for the array `X_{n,i} = ΔS_i / s_n`, `i < n`, with σ-fields `ℱ_i` (nested trivially); `StoutLIL` is Stout (1970) with `V_n = Σ_{i<n} E[ΔS_i² | ℱ_i]` and the `ℱ_{n-1}`-measurable bound `B_n`. Their statement-level soundness is the subject of the separate external-sources audit, not repeated here.

Verdict A: **PASS**. Not found: any hidden assumption, any use of an External beyond the two binders, any junk-valued `multivariateGaussian`.

## 5. Deep check B: `Lower/SharpBulk.lean` (Theorem 1.3(iii), paper `:1742-1756`)

* Lemma 9.1(ii) (`exp_deviation`) requires `Fin m`-indexed martingales for a common filtration with `S i 0 = 0` and increments bounded by `b` at **every** sample point (`∀ i, ∀ t < n, ∀ ω`). The Dynkin martingales `M^{f_i}` are bounded only almost surely (steps are unit steps a.s.). `exists_max_dynkin_large` therefore replaces `S⁰_i = (-σ⁻¹) M^{f_i}` by `S_i` from `Generic.Martingale.exists_martingale_clamp` (file `Generic/Martingale/Clamp.lean`): `M'_t = M_0 + Σ_{j<t} clamp_b(M_{j+1} - M_j)`, a martingale for the same filtration (adapted: continuous image of adapted increments; `Martingale.congr` with the a.s. equality at all times), with sure bound `b = 2B/σ`, `M'_0 = M_0` everywhere, and `M' = M` a.s. at all times. The bracket is preserved: `maxDynkin_predBracket_congr` (a.e. equal processes have a.e. equal `predBracket`), `maxDynkin_predBracket_smul` (`⟨cY, cZ⟩ = c² ⟨Y, Z⟩`), and `ae_predBracket_dynkin` (a.e. `predBracket (M^f) (M^g) n = dynkinBracket (stepProb d ε) f g path n`, proved from `condExp_path_next` and `Σ_e p(e)(…) - (mean)(mean)`), so a.s. `predBracket (S i) (S j) n = dynkinBracket(f_i, f_j)/σ²`, the quantity of Lemma 9.3.
* The event `E` (all diagonal brackets in `[c₀, C₀]`, all off-diagonal at most `δ`) is a path functional of the first `n` steps (`maxDynkin_dynkinBracket_congr`), hence measurable (`maxDynkin_measurableSet`); `μ Eᶜ ≤ ofReal α` is the output of Lemma 9.3 (`hsepE`, with `α = Cs n^{-10}`), and `1 - α ≤ (μ E).toReal` follows. `hdiag`, `hoff` are exactly the a.e. hypotheses of Lemma 9.1 with `ω ∈ E`.
* The constants: `c₀, C₀, Cs` come from `hsep` (depend on `d, ε`); `c, C` of Lemma 9.1 are produced for `(c₀, C₀)` before `β` is chosen (`betaOf CE R = (4√CE)⁻¹ √(log R)`, so `CE β² = log R / 16`); `scale_basic` supplies, for large `n`, `β ≥ CE`, `β · 2B/σ ≤ cE`, `β² δ + β³ (2B/σ) ≤ 1`, `α ≤ 1`, `1 ≤ kOf R`, and the spacing `(i+1) ⌈R^{1/4}⌉ + k ≤ √R` (all sites satisfy `|y| ≤ r_n^{1/2}`); `scale_final` bounds `α + Cu n^{-10} + CE(m⁻¹ e^{CE β²} + β² δ + β³ b + e^{CE β²} √α) ≤ n^{-c1}`. The probability is the sum of four terms: the event of Lemma 9.3, the event of `bulk_potential_only` (from `hfluct`, `p = 10`), the failure event of Lemma 9.1(ii), and a null set where `X 0 ≠ 0` or `|X_j| > j` (`hnull`), exactly the paper's `P(Ω_n^c) + C r_n^{-1/16}`.
* Step 2: `exists_site_single` (`d ≥ 3`) and `exists_site_pair` (`d = 2`, the difference of the decomposition `|ℓ - U + M^y| ≤ P` at `y_i + k e₁` and `y_i`, giving a deviation `T/2 - (P + Eu)` at one of the two sites) are the linear arithmetic of the paper; `bulk_potential_only` is `eq:bulk-potential-only` for `|y| ≤ r_n/2` (`C √(r log n)` for `d = 2`, `C log n` for `d ≥ 3`, i.e. `C r_n q_n`). The sets `{f_i}` and the scales `σ, k, m, y_i` are the same as in the Prop `separated_brackets` (the `refine le_trans (measure_mono ?_) (hsepn …)` is accepted by defeq).
* The conclusion `sharp_bulk_core` is stated with the private `scaleR`, `sigmaOf`; `sharp_bulk_of` closes the Prop `sharp_bulk` by `exact sharp_bulk_core …` after `intro d hd ωd ε hε0 hε1 r`, so `scaleR d ε n` and the `let r` are definitionally equal (accepted).
* `hexp` is applied at the same universe, with `m = kOf R`, `n = n`, and its hypothesis list is met term by term: `0 < m`, `0 < n`, `α ≤ 1`, martingale, `S 0 = 0`, sure increment bound, `MeasurableSet E`, `1 - α ≤ μ(E)`, the a.e. diagonal bracket window, `C ≤ β`, `β b ≤ c`, the a.e. off-diagonal bound, `β²δ + β³b ≤ 1`.

Verdict B: **PASS**. Not found: any use of the lemma on non-martingales, any dependence of `c, C` on `n` or `β`, any gap between the a.s. and sure increment bounds.
