## Reproducing it

```
elan toolchain install $(cat lean-toolchain)
lake build CERW
python3 -m leanform_tools.check_manifest .   # frozen statements match their hashes
python3 -m leanform_tools.check_axioms .     # no axiom closure contains an unregistered sorryAx
python3 -m leanform_tools.check_warnings .   # the build emits no unauthorized warning
python3 -m leanform_tools.certificate . --check
```
